# PixTerm

终端像素画板程序 — 在终端中创建和编辑像素画。

## 功能特性

- **全彩像素绘制**：支持 RGB 全色彩，通过设置空格字符的背景颜色实现像素绘制
- **鼠标操作**：左键绘制、右键擦除、拖拽连续绘制
- **键盘操作**：方向键移动光标、空格绘制、数字键快速切换调色板颜色
- **调色板**：10 个预设颜色（数字键 0-9 切换），支持自定义 Hex 颜色输入
- **撤销/重做**：Ctrl+Z 撤销、Ctrl+Y 重做，拖拽绘制作为整体撤销单元
- **无限画布**：基于 HashMap 稀疏存储，画布大小无固定限制
- **多格式保存/加载**：默认 `.ptd` 压缩格式（gzip），兼容 `.json` 纯文本格式
- **PNG 导入/导出**：支持导出为 PNG 图片，支持从 PNG 图片导入像素
- **命令模式**：ESC 进入，支持多种命令操作
- **帮助覆盖层**：内置帮助信息显示

## 安装与运行

### 前置要求

- Rust 工具链（edition 2024，需要 Rust 1.85+）
- 支持 24-bit 真彩色的终端模拟器

### 编译运行

```bash
# 编译
cargo build --release

# 运行
cargo run --release
```

## 快捷键一览

### 绘制模式

| 快捷键 | 功能 |
|--------|------|
| 鼠标左键点击/拖拽 | 绘制像素 |
| 鼠标右键点击/拖拽 | 橡皮擦（清除像素） |
| 方向键 | 移动键盘光标（自动滚动视口） |
| 空格 | 在键盘光标位置绘制 |
| Delete | 清除键盘光标位置的像素 |
| 数字键 0-9 | 切换调色板颜色 |
| Ctrl+S | 保存画布 |
| Ctrl+Z | 撤销 |
| Ctrl+Y | 重做 |
| Ctrl+Q | 退出 |
| ESC | 进入命令模式 |

### 命令模式（ESC 进入）

| 命令 | 功能 |
|------|------|
| `help` | 显示帮助信息 |
| `save [文件名]` | 保存画布（默认 `canvas.ptd` 压缩格式） |
| `load [文件名]` | 加载画布（默认 `canvas.ptd`） |
| `export [文件名]` | 导出 PNG 图片（默认 `canvas.png`） |
| `import 文件名` | 从 PNG 图片导入像素到画布 |
| `quit` / `q` | 退出程序 |
| `paint x y [#RRGGBB]` | 在指定坐标绘制颜色 |
| `paint x1:x2 y1:y2 [#RRGGBB]` | 在指定范围批量绘制 |
| `undo` | 撤销 |
| `redo` | 重做 |
| `color x y` | 查看指定坐标的颜色 |
| `clear` | 清空画布 |
| `#RRGGBB` | 切换画笔颜色 |

## 文件格式

### .ptd 压缩格式（默认）

`.ptd`（PixTerm Data）是默认存储格式，内部为 gzip 压缩的 JSON 数据，体积远小于纯文本 JSON。

### .json 纯文本格式

通过指定 `.json` 扩展名保存，便于人工阅读和外部工具处理：

```json
{
  "version": "1.0.0",
  "width": 32,
  "height": 32,
  "pixels": [[null, [255,0,0], [0,255,0]], ...]
}
```

- `null` 表示空像素
- `[r, g, b]` 表示有颜色的像素

### PNG 图片格式

通过 `export` / `import` 命令支持 PNG 图片的导出和导入：

- 导出为 RGBA PNG（空像素透明，有色像素不透明）
- 导入时 alpha > 0 的像素写入画布

## 依赖

| 依赖 | 用途 |
|------|------|
| `crossterm` | 终端交互（raw mode、鼠标捕获、事件处理） |
| `serde` / `serde_json` | JSON 序列化/反序列化 |
| `flate2` | gzip 压缩/解压（.ptd 格式） |
| `image` | PNG 图片读写（导入/导出） |
