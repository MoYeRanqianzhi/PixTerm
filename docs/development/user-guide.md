# PixTerm 使用指南

## 快速开始

### 1. 编译并运行

```bash
cargo run --release
```

启动后会看到：
- **画布区域**：占据终端大部分空间，默认背景表示空白无限画布
- **状态栏**：底部倒数第二行，显示模式、画笔颜色、光标坐标等信息
- **调色板栏**：底部最后一行，显示 10 个候选画笔颜色

### 2. 基本绘制

- **鼠标左键点击或拖拽**：在画布上绘制像素（使用当前画笔颜色）
- **鼠标右键点击或拖拽**：橡皮擦模式，清除像素
- **键盘空格键**：在键盘光标位置绘制像素

### 3. 切换颜色

- **数字键 0-9**：快速切换到调色板预设颜色
- **命令模式输入 Hex 颜色**：按 ESC → 输入 `#FF0000` → 按 Enter

默认调色板颜色：

| 键 | 颜色 | Hex |
|----|------|-----|
| 0 | 黑色 | #000000 |
| 1 | 白色 | #FFFFFF |
| 2 | 红色 | #FF0000 |
| 3 | 绿色 | #00FF00 |
| 4 | 蓝色 | #0000FF |
| 5 | 黄色 | #FFFF00 |
| 6 | 品红 | #FF00FF |
| 7 | 青色 | #00FFFF |
| 8 | 橙色 | #FF8000 |
| 9 | 紫色 | #8000FF |

### 4. 导航

- **方向键**：移动键盘光标（视口自动跟随）
- **Ctrl+滚轮**：终端字体缩放（Windows Terminal 内置功能）

### 5. 撤销和重做

- **Ctrl+Z**：撤销上一步操作
- **Ctrl+Y**：重做上一步被撤销的操作
- 鼠标拖拽绘制的多个像素视为一次操作，撤销时整体回退

### 6. 保存和加载

- **Ctrl+S**：快速保存到 `canvas.ptd`（压缩格式）
- **命令模式**：
  - `save` — 保存到默认文件 `canvas.ptd`（压缩格式）
  - `save myart.ptd` — 保存到指定 .ptd 文件（压缩格式）
  - `save myart.json` — 保存到 JSON 文件（纯文本格式，便于人工阅读）
  - `load` — 加载默认文件 `canvas.ptd`
  - `load myart.json` — 从指定文件加载

### 7. 导出和导入 PNG

- **命令模式**：
  - `export` — 导出为默认文件 `canvas.png`
  - `export myart.png` — 导出到指定 PNG 文件
  - `import photo.png` — 从 PNG 图片导入像素到画布

## 命令模式

按 **ESC** 键进入命令模式，底部会显示 `:` 提示符。

输入命令后按 **Enter** 执行，按 **ESC** 取消返回绘制模式。

### 可用命令

| 命令 | 说明 | 示例 |
|------|------|------|
| `help` | 显示帮助覆盖层 | `help` |
| `save [文件名]` | 保存画布（默认 .ptd 压缩格式） | `save`、`save art.ptd`、`save art.json` |
| `load [文件名]` | 加载画布 | `load`、`load art.ptd`、`load art.json` |
| `export [文件名]` | 导出 PNG 图片 | `export`、`export art.png` |
| `import 文件名` | 导入 PNG 图片 | `import photo.png` |
| `quit` / `q` | 退出程序 | `quit` |
| `paint x y [#HEX]` | 绘制单个像素 | `paint 10 5`、`paint 10 5 #FF0000` |
| `paint x1:x2 y1:y2 [#HEX]` | 范围绘制 | `paint 0:10 0:10 #00FF00` |
| `undo` | 撤销 | `undo` |
| `redo` | 重做 | `redo` |
| `color x y` | 查看像素颜色 | `color 10 5` |
| `clear` | 清空画布 | `clear` |
| `#RRGGBB` | 切换画笔颜色 | `#00FF00` |

### paint 命令详解

`paint` 命令用于在指定坐标绘制像素，支持单像素和矩形范围两种模式。

**语法**：`paint <X坐标> <Y坐标> [颜色]`

- **坐标**可以是单个数字或 `起始:结束` 范围
- **颜色**为可选参数（`#RRGGBB` 格式），省略时使用当前画笔颜色

#### 使用示例

```
paint 10 20              → 在 (10,20) 用当前画笔颜色绘制
paint 10 20 #FF0000      → 在 (10,20) 用红色绘制
paint 0:10 5:15          → 用当前画笔颜色填充矩形 x∈[0,10], y∈[5,15]
paint 0:10 5:15 #00FF00  → 用绿色填充矩形 x∈[0,10], y∈[5,15]
paint 5 0:20             → 单列绘制：x=5, y∈[0,20]
paint 0:10 5             → 单行绘制：x∈[0,10], y=5
```

#### 坐标范围规则

- 范围格式为 `起始值:结束值`（包含两端），如 `0:10` 表示 0 到 10
- 起始值必须 ≤ 结束值，否则命令无效
- 单个数字等同于 `n:n`，即 `5` 等同于 `5:5`
- 坐标范围为 `0` 到 `65535`（u16 范围）
- 范围绘制产生的所有像素变化作为一次操作记录，可以一次性撤销

## 界面说明

### 状态栏（倒数第二行）

```
[DRAW] 当前画笔 ██ #000000 | (0,0) | 状态消息
```

- **模式标签**：`DRAW`（蓝色）或 `CMD`（橙色）
- **当前画笔**：显示当前画笔颜色的色块和 Hex 值
- **光标坐标**：键盘光标在画布上的逻辑位置
- **状态消息**：操作反馈信息（黄色文字）

### 调色板栏 / 命令行（最后一行）

**绘制模式**：显示 10 个候选画笔

```
画笔0██ 画笔1██ 画笔2██ ... 画笔9██
```

- 当前选中的画笔以亮白色高亮显示
- 其余画笔以暗灰色显示

**命令模式**：显示命令输入

```
:command_text
```

### 画布区域

- **默认背景**：终端默认背景色表示空白像素
- **反色括号 `[]`**：键盘光标位置标记

## 文件格式

### .ptd 压缩格式（默认）

`.ptd`（PixTerm Data）是 PixTerm 的默认存储格式，使用 gzip 压缩 JSON 数据，大幅减小文件体积。

- `save` 和 `load` 命令默认使用 `canvas.ptd`
- Ctrl+S 快速保存也使用 .ptd 格式
- 不可直接用文本编辑器阅读

### .json 纯文本格式

通过在文件名中指定 `.json` 扩展名可使用纯文本 JSON 格式，便于人工阅读和调试：

```json
{
  "version": "1.0.0",
  "width": 32,
  "height": 32,
  "pixels": [
    [null, [255, 0, 0], null],
    ...
  ]
}
```

- `width` / `height`：画布边界框的宽高（根据实际像素计算）
- `pixels[y][x]`：`null` 为空像素，`[r, g, b]` 为有色像素
- 坐标原点为边界框的左上角

### PNG 图片格式

通过 `export` / `import` 命令可以导出和导入 PNG 图片：

- **导出**：画布像素 → RGBA PNG（空像素为透明，有色像素为不透明）
- **导入**：PNG 像素 → 画布（alpha > 0 的像素写入画布）
- 空画布导出为 1×1 透明 PNG

| 操作 | 默认文件 | 格式 |
|------|---------|------|
| `save` | `canvas.ptd` | `.ptd` → gzip 压缩，`.json` → 纯文本 |
| `load` | `canvas.ptd` | 根据扩展名自动识别 |
| `export` | `canvas.png` | PNG 图片 |
| `import` | —（必须指定）| PNG 图片 |

## 退出程序

- **Ctrl+Q** — 直接退出
- **命令模式** — ESC → 输入 `quit` 或 `q` → Enter

退出后终端会自动恢复到正常状态。
